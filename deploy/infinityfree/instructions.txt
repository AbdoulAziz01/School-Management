  Déploiement School Management — InfinityFree (racine htdocs)
══════════════════════════════════════════════════════════════

1) Structure des fichiers sur le serveur
   - Votre htdocs doit contenir À LA RACINE au minimum :
       index.php           (voir ci‑dessous)
       .htaccess           (copie de htdocs-htaccess, renommé en ".htaccess")
       app/
       bootstrap/
       vendor/             ◄── OBLIGATOIRE (voir section Composer)
       config/
       database/
       public/             peut rester vide ou contenir uniquement favicon/assets
       resources/
       routes/
       storage/            dossier avec droits écriture (sessions, logs, views)
       artisan
       composer.json       (référence seule ; pas indispensable au run si vendor existe)

   - Le dossier "vendor/" : il apparaît après "composer install" en local,
     puis vous uploader TOUT le projet y compris vendor/ vers InfinityFree.

2) Point d’entrée (index.php à la racine htdocs)
   - Au lieu du index.php Laravel standard avec ../vendor, utilisez le fichier :
        deploy/infinityfree/index-htdocs-racine.php
     Renommez-le en "index.php" à la RACINE du htdocs (remplace l’index par défaut),
     OU copiez-collez son CONTENU dans l’index.php déjà placé après déplacement depuis public/

   Les lignes importantes sont :
        require __DIR__.'/vendor/autoload.php';
        $app = require_once __DIR__.'/bootstrap/app.php';

3) Base de données MySQL (InfinityFree Control Panel)
   - Créer une base depuis "MySQL Databases".
   - Noter Hostname / User / Password / nom de base.
   - Dans phpMyAdmin : Importer votre fichier SQL (export depuis votre projet local).

4) Fichier .env sur le serveur
   - Si .env est absent : dupliquer .env.example puis renommer en .env
   - Renseigner obligatoirement :
        APP_ENV=production
        APP_DEBUG=false
        APP_KEY=      (php artisan key:generate en local, puis copier la valeur)
        APP_URL=https://votre-sous-domaine.infinityfreeapp.com

        DB_CONNECTION=mysql
        DB_HOST=...mysql... infinityfree hostname ...
        DB_PORT=3306
        DB_DATABASE=...
        DB_USERNAME=...
        DB_PASSWORD=...

   - Sur mutualisé gratuit, évitez SESSION_DRIVER=database tant que tout n’est pas migré ;
     préférez souvent :
        SESSION_DRIVER=file
        CACHE_STORE=file
        QUEUE_CONNECTION=sync

5) Droits dossier storage/
   - Le serveur doit pouvoir écrire dans :
        storage/framework/
        storage/logs/

6) Laravel 12 nécessite PHP 8.2+
   - Vérifier dans le panneau InfinityFree ou .htaccess "select PHP".

7) Fichiers fournis dans ce dossier deploy/infinityfree/
   index-htdocs-racine.php   → racine Laravel + index fusionné comme au tutoriel
   htdocs-htaccess           → à renommer en .htaccess à la racine htdocs
   instructions.txt          → cette aide
